# Sistema Bancário Simples 🏦

Este é um projeto de sistema bancário simples feito em Python, onde é possível:

- Depositar dinheiro
- Sacar dinheiro
- Consultar extrato
- Sair do sistema

## Tecnologias Utilizadas

- Python 3
